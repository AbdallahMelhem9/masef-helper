TITLE: Triples from 1–9 against triples from 1–8
QUESTION:
Player A picks $3$ distinct integers uniformly at random from $\{1,\dots,9\}$ and writes them in decreasing order, forming a three-digit number (e.g. $\{2,7,5\}\to 752$). Player B does the same with $3$ distinct integers from $\{1,\dots,8\}$.

What is the probability that A's number is strictly larger than B's? Solve it by hand.
HINT1:
The two players are almost in the same situation. What is the one thing A can have that B can never have?
HINT2:
Split on whether A's triple contains a $9$. If it does, A wins for sure. If it does not, A's triple is a uniform $3$-subset of $\{1,\dots,8\}$, exactly like B's: use symmetry, but remember ties.
ANSWER:
$\dfrac{37}{56}$
REFRESH:
- **Lexicographic order**: two numbers written with digits in decreasing order compare like their largest digits first, then second largest, then smallest.
- **Symmetry**: if $U$ and $V$ are i.i.d., then $P(U>V)=P(V>U)=\frac{1-P(U=V)}{2}$.
EXPLANATION:
A has one extra card in their deck: the $9$. Whenever A draws it, A's number starts with a $9$ while B's starts with at most an $8$, so A wins outright. Whenever A does not draw it, A is drawing from exactly the same pool as B, and the game is perfectly symmetric: A wins as often as B, and the only thing to subtract is the chance of an exact tie.

The probability A draws the $9$ is $\frac{3}{9}=\frac13$ (the $9$ is one of $9$ equally likely numbers and A takes $3$ of them). Conditional on no $9$, A's triple is uniform among the $\binom83=56$ subsets of $\{1,\dots,8\}$, independent of B's, so a tie has probability $\frac1{56}$ and A wins with probability $\frac12\left(1-\frac1{56}\right)=\frac{55}{112}$.
SOLUTION: Condition on the 9
Let $N$ be the event that A's triple contains $9$. There are $\binom93=84$ triples for A, and $\binom82=28$ of them contain $9$, so $P(N)=\frac{28}{84}=\frac13$.

On $N$, A's leading digit is $9$ and B's leading digit is at most $8$, so A wins: $P(\text{A wins}\mid N)=1$.

On $N^c$, A's triple is uniform among the $\binom83=56$ triples from $\{1,\dots,8\}$, and so is B's, independently. Distinct triples give distinct numbers, so
$$P(\text{tie}\mid N^c)=\frac{56}{56^2}=\frac1{56},\qquad P(\text{A wins}\mid N^c)=\frac{1-\frac1{56}}{2}=\frac{55}{112}.$$
Therefore
$$P(\text{A wins})=\frac13\cdot 1+\frac23\cdot\frac{55}{112}=\frac{56}{168}+\frac{55}{168}=\frac{111}{168}=\frac{37}{56}\approx 0.661.$$
===END===

Fourteen cards labelled $1$ to $14$ are laid in a row in uniformly random order. Position $i$ is a **peak** if its number is larger than each of its neighbours (the two end positions have only one neighbour). For example, with $6$ cards, $513246$ has $3$ peaks: positions $1$, $3$ and $6$.

What is the expected number of peaks?
HINT1:
Counting peaks directly over all $14!$ orders is hopeless. Write the count as a sum of simple indicators.
HINT2:
By linearity of expectation you only need, for each position, the probability that it is a peak. For an end position this involves $2$ cards, for an interior position $3$ cards.
ANSWER:
$5$
REFRESH:
- **Linearity of expectation**: $E[\sum_i I_i]=\sum_i P(I_i=1)$ for indicators, with no independence needed.
- In a uniform random permutation, any fixed set of $m$ positions contains $m$ distinct values in uniformly random relative order.
EXPLANATION:
Whether a position is a peak depends only on the relative order of that card and its neighbours. For an end position, it is a peak if it beats its single neighbour, which happens half the time. For an interior position, it is a peak if it is the largest of three cards, which happens a third of the time. Linearity lets us add these up even though neighbouring peaks are strongly dependent (two adjacent positions can never both be peaks).
SOLUTION: Indicators and linearity
Let $I_i=1$ if position $i$ is a peak. Then the number of peaks is $P=\sum_{i=1}^{14}I_i$.

- $i=1$ or $i=14$: the peak condition compares $2$ distinct values in random order, so $P(I_i=1)=\frac12$.
- $2\le i\le 13$ (twelve positions): the card at $i$ must be the largest of $3$ values in random relative order, so $P(I_i=1)=\frac13$.

Hence
$$E[P]=2\cdot\frac12+12\cdot\frac13=1+4=5.$$
In general, for $n\ge2$ cards, $E[P]=1+\frac{n-2}{3}=\frac{n+1}{3}$.

TITLE: Variance of fixed minus moved
QUESTION:
A permutation of $(1,2,\dots,1000)$ is chosen uniformly at random. Let $Y$ be the number of elements that stay in their original position (fixed points) and $X$ the number of elements that move. Find $\operatorname{Var}(Y-X)$.
HINT1:
$X$ and $Y$ are not two separate random quantities: they are tied together by a simple identity.
HINT2:
Since $X+Y=1000$, write $Y-X$ as an affine function of $Y$ alone, then compute $\operatorname{Var}(Y)$ with indicators $I_i=\mathbf 1\{\sigma(i)=i\}$.
ANSWER:
$4$
REFRESH:
- $\operatorname{Var}(aY+b)=a^2\operatorname{Var}(Y)$.
- $\operatorname{Var}\left(\sum_i I_i\right)=\sum_i\operatorname{Var}(I_i)+\sum_{i\ne j}\operatorname{Cov}(I_i,I_j)$.
EXPLANATION:
Every element either stays or moves, so $X=1000-Y$ and $Y-X=2Y-1000$: all the randomness is in the number of fixed points. The famous fact is that the number of fixed points of a random permutation has mean $1$ and variance $1$ for any $n\ge2$ (it is approximately Poisson$(1)$). Doubling a random variable multiplies its variance by $4$.
SOLUTION: Indicators
Let $n=1000$ and $I_i=\mathbf 1\{\sigma(i)=i\}$, so $Y=\sum_i I_i$ and $X=n-Y$, hence $Y-X=2Y-n$ and $\operatorname{Var}(Y-X)=4\operatorname{Var}(Y)$.

$P(I_i=1)=\frac1n$, so $\operatorname{Var}(I_i)=\frac1n\left(1-\frac1n\right)$. For $i\ne j$, $P(I_i=I_j=1)=\frac{(n-2)!}{n!}=\frac1{n(n-1)}$, so
$$\operatorname{Cov}(I_i,I_j)=\frac1{n(n-1)}-\frac1{n^2}=\frac1{n^2(n-1)}.$$
Summing over the $n$ diagonal terms and the $n(n-1)$ ordered pairs:
$$\operatorname{Var}(Y)=n\cdot\frac1n\left(1-\frac1n\right)+n(n-1)\cdot\frac1{n^2(n-1)}=1-\frac1n+\frac1n=1.$$
Therefore $\operatorname{Var}(Y-X)=4\cdot1=4$.

- $P(X=a_n)=P(U_n<\frac1n)=\frac1n$;

$$P(X=a_k)=\frac1{n-1}\cdot\left(1-\frac1n\right)=\frac1{n-1}\cdot\frac{n-1}{n}=\frac1n.$$

For $k\le n$, $a_k$ is in $X$ after step $n$ iff it was selected at step $k$ and not replaced at steps $k+1,\dots,n$:
$$P(X=a_k)=\frac1k\prod_{j=k+1}^{n}\left(1-\frac1j\right)=\frac1k\prod_{j=k+1}^{n}\frac{j-1}{j}=\frac1k\cdot\frac{k}{n}=\frac1n,$$

HINT2:
Set $y_i=6-x_i\in\{0,\dots,5\}$. Then $y_1+y_2+y_3+y_4=4$: count non-negative solutions with stars and bars.
ANSWER:
$\dfrac{35}{1296}$
REFRESH:
- **Stars and bars**: the number of solutions of $y_1+\dots+y_k=m$ in non-negative integers is $\binom{m+k-1}{k-1}$.
- Sum symmetry for dice: the distribution of the sum of $n$ dice is symmetric about $3.5n$.
EXPLANATION:
Counting sums near the top of the range is easy if you look down from the maximum. Each die "misses" $6$ by some amount $y_i$, and the four misses must total $24-20=4$. Since no miss can exceed $5$, the cap never bites, and the count is a plain stars-and-bars number. Equivalently, by the symmetry $x\mapsto7-x$, $P(\text{sum}=20)=P(\text{sum}=8)$.
SOLUTION: Stars and bars
With $y_i=6-x_i\ge0$: $\sum y_i=24-20=4$. Each $y_i\le4<6$ automatically, so the number of solutions is
$$\binom{4+3}{3}=\binom73=35.$$
Out of $6^4=1296$ equally likely outcomes:
$$P=\frac{35}{1296}\approx0.027.$$
SOLUTION: Listing multisets
Four faces summing to $20$ (as multisets) and their numbers of orderings: $\{6,6,6,2\}$: $4$; $\{6,6,5,3\}$: $12$; $\{6,6,4,4\}$: $6$; $\{6,5,5,4\}$: $12$; $\{5,5,5,5\}$: $1$. Total $4+12+6+12+1=35$, giving $\frac{35}{1296}$.

TITLE: Last queen before last king
QUESTION:
Eve shuffles a standard $52$-card deck thoroughly. She wins \$100 if the last queen in the deck appears before the last king. Her friend Jenny looks at the order of the cards and tells Eve that exactly two queens come before the first king. Given this information, what are Eve's expected winnings?
HINT1:
Only the relative order of the $4$ queens and $4$ kings matters. What does Jenny's statement tell you about the first few of those $8$ cards?
HINT2:
Among the $8$ court cards, the order starts $Q,Q,K$. The remaining $2$ queens and $3$ kings are in uniformly random order. Eve wins exactly when the last of the $8$ is a king.
ANSWER:
\$60
REFRESH:
- The relative order of any fixed subset of cards in a uniform shuffle is uniformly random; conditioning on the first few positions leaves the rest uniformly random.
EXPLANATION:
Strip the deck down to its $8$ queens and kings. "The last queen comes before the last king" just means "the very last of these $8$ cards is a king". Jenny tells you the pattern starts $Q,Q,K$. That uses up $2$ queens and $1$ king; the $5$ remaining cards ($2$ queens and $3$ kings) are in random order, so the last one is a king with probability $\frac35$. Without Jenny's information the chance would be $\frac12$; her news helps because it shows queens were "spent" early.
SOLUTION: Reduce to the court cards
Look only at the sequence of the $4$ queens and $4$ kings; in a uniform shuffle all $\binom84=70$ patterns are equally likely. Eve wins iff the last card of this sequence is a king.

Jenny's information: the pattern starts $QQK$. Conditioned on this, the last $5$ positions hold $2$ Q's and $3$ K's in uniformly random order (all $\binom52=10$ patterns equally likely). The last position is a king with probability $\frac35$. Hence
$$E[\text{winnings}]=100\cdot\frac35=\$60.$$

TITLE: A three-digit safe code
QUESTION:
An electronic safe opens with a three-digit code ($000$ to $999$, leading zeros allowed). You know that: the code is not odd; it does not contain the digit $6$; and at least one digit is repeated. How many codes satisfy all three conditions?
HINT1:
"At least one repeat" is awkward to count directly. What is its complement?
HINT2:
Count codes that are even with no $6$, then subtract those whose three digits are all distinct.
ANSWER:
$100$
REFRESH:
- **Complementary counting**: $\#(\text{at least one repeat})=\#(\text{all})-\#(\text{all distinct})$.
- **Multiplication principle**: fill positions one by one, multiplying the number of choices.
EXPLANATION:
Nine digits are allowed ($0$–$9$ without $6$), and the last digit must be even, i.e. one of $0,2,4,8$. SOLUTION: Complement
All codes that are even and avoid $6$: first digit $9$ choices, middle $9$, last $4$ ($0,2,4,8$): $9\cdot9\cdot4=324$.

All-distinct such codes: last digit $4$ choices, then first digit $8$ remaining choices, then middle $7$: $4\cdot8\cdot7=224$.

Codes with at least one repeated digit:
$$324-224=100.$$
(If the code had to be a genuine three-digit number with no leading zero, the same method gives $288-203=85$.)

FIRMS: Jane Street
SECTION: probability
CATEGORY: Games & optimal stopping
DIFFICULTY: medium
TITLE: Rock-paper-scissors without rock
QUESTION:
You play rock-paper-scissors against an opponent who is not allowed to play rock. A win pays you $1$, a loss costs you $1$, a tie pays $0$. Both of you play optimally (the opponent tries to minimise your gain). What is your expected gain per round?
HINT1:
Write the $3\times2$ payoff table (your three moves against paper or scissors). Is one of your moves now dominated?
HINT2:
Paper never beats anything the opponent can play, so you mix rock and scissors. Choose the mix that makes you indifferent to whether the opponent plays paper or scissors.
ANSWER:
$\dfrac13$ per round (play rock with probability $\frac13$, scissors with probability $\frac23$)
REFRESH:
- **Mixed-strategy equilibrium** of a zero-sum game: each player randomises so that the other is indifferent between the moves they use; the resulting common payoff is the value of the game (minimax theorem).
EXPLANATION:
The opponent only has paper and scissors. Scissors beats paper and ties with scissors, so it never loses: it is a safe move for you. Rock wins against their scissors but loses to their paper. Paper is useless (tie or loss). If you played scissors always, the opponent would play scissors and you would get $0$; so you add some rock to punish their scissors. The right amount of rock makes their choice irrelevant, and that locks in a positive edge of $\frac13$ per round.
SOLUTION: Indifference
Your payoff (rows: you; columns: opponent):

| | Paper | Scissors |
|---|---|---|
| Rock | $-1$ | $+1$ |
| Paper | $0$ | $-1$ |
| Scissors | $+1$ | $0$ |

Paper is dominated by scissors (scissors is at least as good against both columns), so mix rock with probability $r$ and scissors with probability $1-r$:
- against paper: $-r+(1-r)=1-2r$;
- against scissors: $r$.

Setting them equal: $1-2r=r$, so $r=\frac13$ and you guarantee $\frac13$ whatever the opponent does.

The opponent cannot hold you below that: if they play paper with probability $q$, your three moves earn $1-2q$ (rock), $q-1$ (paper), $q$ (scissors). The opponent minimises the best of these; $1-2q=q$ at $q=\frac13$ gives $\max=\frac13$. Both bounds agree, so the value is $\frac13$.
===END===

CATEGORY: Counting & combinatorics
DIFFICULTY: medium
TITLE: Three ones in a row in five rolls
QUESTION:
A fair die is rolled $5$ times. What is the probability that the sequence contains at least $3$ consecutive $1$s?
HINT1:
A run of three $1$s can start at roll $1$, $2$ or $3$. These events overlap, so do not just add their probabilities.
HINT2:
Classify by the position of the first run of three: starting at roll $1$; starting at roll $2$ with roll $1$ not a $1$; starting at roll $3$ with roll $2$ not a $1$. These are disjoint.
ANSWER:
$\dfrac1{81}$
REFRESH:
- To avoid double counting overlapping events, split by the first occurrence: disjoint cases whose probabilities add.
- **Inclusion–exclusion**: $P(A\cup B\cup C)=\sum P(A)-\sum P(A\cap B)+P(A\cap B\cap C)$.
EXPLANATION:
Each window of three rolls is all $1$s with probability $\frac1{216}$, but windows overlap (a run of four $1$s lies in two windows), so we identify each good sequence by where its first run of three starts. A run starting at roll $2$ or $3$ is the "first" one only if the roll just before it is not a $1$, which costs a factor $\frac56$.
SOLUTION: First run of three
Let $p=\frac16$.
- First run starts at roll $1$: rolls $1$–$3$ are $1$s: $p^3$.
- First run starts at roll $2$: roll $1$ is not a $1$, rolls $2$–$4$ are $1$s: $(1-p)p^3$.
- First run starts at roll $3$: roll $2$ is not a $1$, rolls $3$–$5$ are $1$s (roll $1$ arbitrary): $(1-p)p^3$. (Roll $1$ being a $1$ cannot create an earlier run since roll $2$ is not a $1$.)

These cases are disjoint and exhaustive, so
$$P=p^3\left(1+2\cdot\tfrac56\right)=\frac1{216}\cdot\frac{8}{3}=\frac{8}{648}=\frac1{81}.$$
SOLUTION: Inclusion–exclusion
Let $A_k$ = rolls $k,k+1,k+2$ are all $1$ ($k=1,2,3$). $P(A_k)=\frac1{216}$. $A_1\cap A_2$ and $A_2\cap A_3$ need four $1$s: $\frac1{1296}$ each; $A_1\cap A_3$ and $A_1\cap A_2\cap A_3$ need five $1$s: $\frac1{7776}$ each. So
$$P=\frac3{216}-\frac2{1296}-\frac1{7776}+\frac1{7776}=\frac{108-12}{7776}=\frac{96}{7776}=\frac1{81}.$$
===END===
