SLUG: three-face-die-coins-until-repeat
IDS: Q-125
FIRMS: Akuna Capital
SECTION: probability
CATEGORY: Expected value
DIFFICULTY: medium
TITLE: Coins until a repeated face
QUESTION:
A six-sided die has faces $1, 2, 3, 1, 2, 3$ (so each of $1, 2, 3$ comes up with probability $1/3$). You roll it repeatedly and after each roll you receive as many coins as the face shown. The game stops as soon as two consecutive rolls show the same face (the coins of that last roll are still paid). What is the expected total number of coins you receive?
HINT1:
Separate two questions: how many rolls do you expect to make, and how much is an average roll worth?
HINT2:
After the first roll, each new roll repeats the previous face with probability $1/3$, independently of the past, so the number of rolls is $1$ plus a geometric variable. Then check whether you may multiply "expected number of rolls" by "expected value of a roll".
ANSWER:
8 coins
REFRESH:
Geometric distribution: if each trial succeeds with probability $p$ independently, the number of trials up to and including the first success has mean $1/p$.
Wald's identity: if $X_1, X_2, \dots$ are i.i.d. with finite mean and $N$ is a stopping time with $\mathbb{E}N < \infty$ (whether to stop after roll $n$ depends only on $X_1,\dots,X_n$), then $\mathbb{E}\big[\sum_{i=1}^N X_i\big] = \mathbb{E}N \cdot \mathbb{E}X_1$.
EXPLANATION:
The rolls themselves are i.i.d. with mean $2$. The rule for stopping only looks at rolls already made, so it is a stopping time, and Wald's identity says the total is on average (number of rolls) $\times$ (mean roll). The number of rolls is $1 + \text{Geometric}(1/3)$: the first roll can never end the game, and every later roll ends it with probability exactly $1/3$ whatever came before. So $\mathbb{E}N = 1 + 3 = 4$ and the expected total is $4 \times 2 = 8$.

It is tempting to worry that the rolls that end the game are "special" and so bias the average. They are special in the sense that they equal the previous roll, but the previous roll is itself uniform on $\{1,2,3\}$, so there is no bias: Wald's identity takes care of this rigorously.
SOLUTION: Wald's identity
Let $X_1, X_2, \dots$ be the rolls, i.i.d. uniform on $\{1,2,3\}$, so $\mathbb{E}X_i = 2$. Let $N$ be the index of the roll that ends the game, i.e. the first $n \ge 2$ with $X_n = X_{n-1}$.

For $n \ge 2$, given the whole past $X_1,\dots,X_{n-1}$, the event $X_n = X_{n-1}$ has probability $1/3$. So the rolls $2, 3, \dots$ are independent trials each "succeeding" with probability $1/3$, and $N - 1 \sim \text{Geometric}(1/3)$ on $\{1,2,\dots\}$:
$$\mathbb{E}N = 1 + \frac{1}{1/3} = 4.$$
The event $\{N \le n\}$ depends only on $X_1, \dots, X_n$, so $N$ is a stopping time with finite mean. By Wald's identity
$$\mathbb{E}\Big[\sum_{i=1}^N X_i\Big] = \mathbb{E}N \cdot \mathbb{E}X_1 = 4 \times 2 = 8.$$
SOLUTION: First-step recursion
Let $V_a$ be the expected number of coins still to come when the last roll showed $a$ (not counting that roll). The next roll $r$ is uniform on $\{1,2,3\}$ and pays $r$; if $r = a$ the game stops, otherwise we are in state $r$:
$$V_a = \underbrace{\tfrac{1+2+3}{3}}_{=2} + \frac{1}{3}\sum_{r \ne a} V_r .$$
Add the three equations, with $S = V_1 + V_2 + V_3$: $S = 6 + \frac{1}{3}\cdot 2S$, so $S = 18$. Then $V_a = 2 + \frac{S - V_a}{3}$ gives $\frac{4}{3}V_a = 8$, i.e. $V_a = 6$ for every $a$.

The first roll pays $2$ on average and puts us in some state $a$, after which $6$ more coins are expected. Total: $2 + 6 = 8$.
===END===

SLUG: die-see-every-face-twice
IDS: Q-126
FIRMS: Jane Street
SECTION: probability
CATEGORY: Expected value
DIFFICULTY: hard
TITLE: Every face once, then every face twice
QUESTION:
You roll a fair six-sided die repeatedly.

1. What is the expected number of rolls until each of the faces $1,\dots,6$ has appeared at least once?
2. What is the expected number of rolls until each face has appeared at least **twice**?

For part 2, explain why it is wrong to split the process into two independent phases ("first collect one of each face, then collect a second copy of each face"), and compute the expectation by treating the whole sequence of rolls at once, for instance with the tail-sum formula $\mathbb{E}T = \sum_{n \ge 0}\mathbb{P}(T > n)$.
HINT1:
Part 1 is the coupon collector. For part 2, think about what the counts look like at the moment the last new face first appears: are they all equal to 1?
HINT2:
For part 2, $T \le n$ means that in $n$ rolls every face occurs at least twice; count such sequences with the exponential generating function $(e^x - 1 - x)^6$. Summing the tail $\mathbb{P}(T>n)$ over $n$ becomes an integral once you write $n! = \int_0^\infty t^n e^{-t}\,dt$.
ANSWER:
Once: $14.7$ rolls. Twice: $\frac{390968681}{16200000} \approx 24.13$ rolls.
REFRESH:
Tail-sum formula: for a random variable $T$ with values in $\{0,1,2,\dots\}$, $\mathbb{E}T = \sum_{n\ge 0}\mathbb{P}(T>n)$.
Exponential generating functions: the number of words of length $n$ over 6 letters in which each letter appears a number of times allowed by a set $A$ is $n!\,[x^n]\big(\sum_{k\in A} x^k/k!\big)^6$.
Gamma integral: $\int_0^\infty t^n e^{-t}\,dt = n!$.
EXPLANATION:
Part 1 is the classic coupon collector: when $k$ faces have been seen, a new one appears with probability $(6-k)/6$, so the waiting time for it is geometric with mean $6/(6-k)$. Summing gives $6(1 + \tfrac12 + \dots + \tfrac16) = 14.7$.

For part 2 the "two phases" idea fails because the phases overlap. While we are still waiting for the last new face, the other faces keep being rolled, so at the moment all six have been seen, several faces already have two or more copies. The second phase therefore does not start from "all counts equal to 1"; how far along it already is depends on how long the first phase took. Adding $14.7 + 14.7 = 29.4$ badly overestimates (and even the second phase alone is not a clean coupon collector).

The clean route is the tail sum. $\mathbb{P}(T > n)$ is the probability that after $n$ rolls some face has fewer than two copies, which is a counting problem for words of length $n$. Exponential generating functions do this counting, and the sum over $n$ turns into a single integral:
$$\mathbb{E}T = 6\int_0^\infty \Big[1 - \big(1 - e^{-s}(1+s)\big)^6\Big]\,ds .$$
This has a nice reading: imagine the rolls arrive as a Poisson process of rate 1, so each face arrives as an independent Poisson process of rate $1/6$. $e^{-s}(1+s)$ is the probability that a face has fewer than 2 arrivals by time $6s$, and the integral is the expected time until all six faces have 2 arrivals. The same formula with $e^{-s}$ in place of $e^{-s}(1+s)$ gives back $14.7$.
SOLUTION: Coupon collector, then tail sum with generating functions
**Part 1.** Let $T_k$ be the number of rolls needed to go from $k$ distinct faces seen to $k+1$. Each roll shows a new face with probability $(6-k)/6$, so $T_k$ is geometric with mean $6/(6-k)$:
$$\mathbb{E}T^{(1)} = \sum_{k=0}^{5}\frac{6}{6-k} = 6\Big(1+\tfrac12+\tfrac13+\tfrac14+\tfrac15+\tfrac16\Big) = 6\cdot\frac{49}{20} = 14.7 .$$

**Part 2: why not two phases.** Let $\tau$ be the time all faces have appeared once. At time $\tau$ the face just seen has exactly one copy, but the others have typically been rolled several times while we waited. The number of faces still lacking a second copy at time $\tau$ is random and depends on $\tau$ (a long first phase means most faces are already doubled). So the second phase is not an independent copy of anything, and its length is not $14.7$.

**Part 2: tail sum.** Let $T$ be the first time every face has at least two copies. $T \le n$ exactly when, in the first $n$ rolls, every face appears at least twice. The number of such words of length $n$ is $n!\,[x^n]\,(e^x - 1 - x)^6$, since $e^x - 1 - x = \sum_{k\ge 2}x^k/k!$. Also $6^n = n!\,[x^n]\,e^{6x}$. Hence
$$\mathbb{P}(T>n) = \frac{n!}{6^n}[x^n]\,G(x), \qquad G(x) = e^{6x} - (e^x-1-x)^6 = \sum_n g_n x^n .$$
Using $n! = \int_0^\infty t^n e^{-t}dt$ (all terms are non-negative, so sum and integral can be swapped):
$$\mathbb{E}T = \sum_{n\ge0}\frac{n!}{6^n}g_n = \int_0^\infty e^{-t}\sum_n g_n\Big(\frac t6\Big)^n dt = \int_0^\infty e^{-t}G(t/6)\,dt .$$
Substitute $t = 6s$ and use $e^{-6s}(e^s - 1 - s)^6 = \big(1 - e^{-s}(1+s)\big)^6$:
$$\mathbb{E}T = 6\int_0^\infty\Big[1 - \big(1-u(s)\big)^6\Big]ds, \qquad u(s) = e^{-s}(1+s).$$
Expand $1-(1-u)^6 = \sum_{j=1}^6\binom6j(-1)^{j+1}u^j$ and use
$$\int_0^\infty e^{-js}(1+s)^j ds = \sum_{i=0}^{j}\binom ji\frac{i!}{j^{i+1}} .$$
The six integrals are $I_1 = 2$, $I_2 = \tfrac54$, $I_3 = \tfrac{26}{27}$, $I_4 = \tfrac{103}{128}$, $I_5 = \tfrac{2194}{3125}$, $I_6 = \tfrac{1223}{1944}$, and
$$\mathbb{E}T = 6\big(6I_1 - 15I_2 + 20I_3 - 15I_4 + 6I_5 - I_6\big) = \frac{390968681}{16200000} \approx 24.134 .$$
(A simulation of $2\times10^5$ games gives $24.14$.) Sanity check: with $u = e^{-s}$ the same formula gives $6\sum_j \binom6j(-1)^{j+1}/j = 6H_6 = 14.7$, the part 1 answer.
===END===

SECTION: probability

TITLE: Correlation of ones and fives
QUESTION:
A fair six-sided die is rolled $n$ times. Let $X$ be the number of 1s and $Y$ the number of 5s. Find $\operatorname{Corr}(X,Y)$.
HINT1:
Write $X$ and $Y$ as sums of indicators, one per roll. Which pairs of indicators are correlated?
HINT2:
Indicators from different rolls are independent. On the same roll, "it is a 1" and "it is a 5" cannot both happen, so their product is $0$.
ANSWER:
$-1/5$ (for every $n$)
REFRESH:
Covariance is bilinear: $\operatorname{Cov}(\sum_i A_i, \sum_j B_j) = \sum_{i,j}\operatorname{Cov}(A_i,B_j)$.
For an indicator of an event with probability $p$: mean $p$, variance $p(1-p)$.
$\operatorname{Corr}(X,Y) = \operatorname{Cov}(X,Y)/\sqrt{\operatorname{Var}X\operatorname{Var}Y}$.
EXPLANATION:
$X$ and $Y$ compete for the same $n$ rolls: every roll that is a 1 is a roll that cannot be a 5, so they are negatively correlated. All the covariance comes from within a single roll, where the two indicators are mutually exclusive, and it is $-\frac16\cdot\frac16$ per roll. Each count has variance $n\cdot\frac16\cdot\frac56$. The ratio does not depend on $n$:
$$\operatorname{Corr} = \frac{-n/36}{5n/36} = -\frac15 .$$
In general, for multinomial counts with probabilities $p_i, p_j$, $\operatorname{Corr} = -\sqrt{\frac{p_ip_j}{(1-p_i)(1-p_j)}}$.
SOLUTION: Indicators
Let $A_k = \mathbf 1\{\text{roll }k = 1\}$, $B_k = \mathbf 1\{\text{roll }k = 5\}$, so $X = \sum_k A_k$, $Y = \sum_k B_k$.

- $\operatorname{Var}X = n\cdot\frac16\cdot\frac56 = \frac{5n}{36}$, and likewise $\operatorname{Var}Y = \frac{5n}{36}$.
- For $k \ne l$, $A_k$ and $B_l$ are independent, so $\operatorname{Cov}(A_k,B_l) = 0$.
- For the same roll, $A_kB_k = 0$, so $\operatorname{Cov}(A_k,B_k) = 0 - \frac16\cdot\frac16 = -\frac1{36}$.

Hence $\operatorname{Cov}(X,Y) = -\frac{n}{36}$ and
$$\operatorname{Corr}(X,Y) = \frac{-n/36}{\sqrt{\frac{5n}{36}\cdot\frac{5n}{36}}} = -\frac15 .$$
SOLUTION: Variance of the sum
$X + Y$ counts rolls showing a 1 or a 5, so $X+Y \sim \text{Bin}(n, 1/3)$ and $\operatorname{Var}(X+Y) = n\cdot\frac13\cdot\frac23 = \frac{8n}{36}$. But also
$$\operatorname{Var}(X+Y) = \operatorname{Var}X + \operatorname{Var}Y + 2\operatorname{Cov}(X,Y) = \frac{10n}{36} + 2\operatorname{Cov}(X,Y).$$
So $\operatorname{Cov}(X,Y) = \frac12\big(\frac{8n}{36} - \frac{10n}{36}\big) = -\frac{n}{36}$, and dividing by $\frac{5n}{36}$ gives $-\frac15$.
===END===

TITLE: Rolling the same pair again
QUESTION:
Two fair six-sided dice are rolled and the pair of numbers shown is noted. Both dice are then rolled a second time. What is the probability that the second roll shows the same pair of numbers as the first, where the order does not matter (for example, a 2 and a 5 the first time and a 5 and a 2 the second time counts as the same)?
HINT1:
Not every first roll is equally easy to repeat. Compare a double like $(3,3)$ with a mixed pair like $(2,5)$.
HINT2:
Condition on whether the first roll was a double. A double can be repeated in $1$ of the $36$ ordered outcomes, a mixed pair in $2$.
ANSWER:
$11/216$
REFRESH:
Law of total probability: $\mathbb{P}(A) = \sum_i \mathbb{P}(A\mid B_i)\mathbb{P}(B_i)$ for a partition $(B_i)$.
EXPLANATION:
The unordered pair you must repeat is random, and its difficulty depends on its type. A double such as $\{3,3\}$ is hit again only by the ordered outcome $(3,3)$: probability $1/36$. A mixed pair $\{2,5\}$ is hit by $(2,5)$ and $(5,2)$: probability $2/36$. The first roll is a double with probability $6/36$ and mixed with probability $30/36$, so
$$\mathbb{P} = \frac{6}{36}\cdot\frac1{36} + \frac{30}{36}\cdot\frac2{36} = \frac{66}{1296} = \frac{11}{216}.$$
If the dice were distinguishable and each had to repeat its own number, the answer would simply be $1/36$; the unordered reading adds the extra chances from swapped pairs.
SOLUTION: Condition on the type of the first roll
The 36 ordered outcomes of the first roll are equally likely.

- Double (6 outcomes, probability $\frac16$): the second roll matches only if it is the same ordered double, probability $\frac1{36}$.
- Mixed pair (30 outcomes, probability $\frac56$): the second roll matches if it shows the two numbers in either order, probability $\frac{2}{36}$.

$$\mathbb{P}(\text{match}) = \frac16\cdot\frac1{36} + \frac56\cdot\frac{2}{36} = \frac{1 + 10}{216} = \frac{11}{216} \approx 0.051 .$$
SOLUTION: Sum of squared probabilities
Group the 36 ordered outcomes into 21 unordered pairs: 6 doubles of probability $\frac1{36}$ and 15 mixed pairs of probability $\frac2{36}$. Two independent rolls give the same unordered pair with probability $\sum_{\text{pairs}}\mathbb{P}(\text{pair})^2$:
$$6\Big(\frac1{36}\Big)^2 + 15\Big(\frac2{36}\Big)^2 = \frac{6 + 60}{1296} = \frac{11}{216}.$$
===END===

$$\mathbb{E}[X+Y] = 3.5 + 3.5 = 7.$$

$(X,Y)$ is uniform over the $30$ ordered pairs of distinct faces. Each face appears as the second coordinate in exactly $5$ of them, so $Y$ is uniform on $\{1,\dots,6\}$ and $\mathbb{E}Y = 3.5$. Hence $\mathbb{E}[X+Y] = 7$.

|---|---|---|---|---|---|---|

If rounds are i.i.d. and the game stops at the first round in event $E$, the number of rounds before the last one has mean $\frac{1-\mathbb{P}(E)}{\mathbb{P}(E)}$, and each of those rounds is distributed as a round conditioned on $E^c$.
EXPLANATION:
Doubles happen in $10$ of the $100$ outcomes, so the game lasts $10$ rounds on average, $9$ of which are non-final. A paying outcome (blue $-$ red $\ge 3$) occurs in $7 + 6 + \dots + 1 = 28$ of the $100$ outcomes, i.e. in $28$ of the $90$ non-doubles. Each non-final round pays with probability $28/90$, so the expected earnings are $9\cdot\frac{28}{90} = 2.8$. Equivalently, compare the two event rates directly: paying rounds occur at rate $28$ and ending rounds at rate $10$ per 100 rolls, so on average $28/10$ payments happen before the end.
SOLUTION: Rate ratio
Count ordered outcomes (red $r$, blue $b$): doubles $b = r$: $10$. Paying $b - r = d$ with $d \in\{3,\dots,9\}$: $10 - d$ each, total $7+6+5+4+3+2+1 = 28$.

Let $V$ be the expected earnings. Conditioning on the first round:
$$V = \frac{28}{100}(1 + V) + \frac{62}{100}V + \frac{10}{100}\cdot 0 \quad\Longrightarrow\quad \frac{10}{100}V = \frac{28}{100} \quad\Longrightarrow\quad V = \frac{28}{10} = \frac{14}{5}.$$
SOLUTION: Wald's identity
The number of rounds $N$ is geometric with success probability $\frac1{10}$, so $\mathbb{E}N = 10$. The payment in round $n$ is $\mathbf 1\{b_n - r_n \ge 3\}$, i.i.d. with mean $0.28$, and $N$ is a stopping time, so $\mathbb{E}[\text{earnings}] = \mathbb{E}N\cdot 0.28 = 2.8$ (the final round, a double, pays 0 automatically and is included harmlessly).
===END===
