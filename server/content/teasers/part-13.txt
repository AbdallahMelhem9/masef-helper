SLUG: rand7-to-rand10
IDS: Q-430, Q-156
FIRMS: Goldman Sachs, Jane Street
SECTION: probability
CATEGORY: Counting & combinatorics
DIFFICULTY: medium
TITLE: Build a fair 1–10 from a fair 1–7
QUESTION:
You have a function `rand7()` that returns an integer from $1$ to $7$, each with probability $1/7$, independently on every call. Using only `rand7()`, construct a procedure that returns an integer from $1$ to $10$, each with probability exactly $1/10$. How many calls does your procedure use on average?
HINT1:
One call gives only $7$ equally likely outcomes, and $10$ does not divide $7$. What happens to the number of equally likely outcomes if you call the function twice?
HINT2:
Two calls give $49$ equally likely ordered pairs. Keep a block of them whose size is a multiple of $10$, and do something about the rest so that you never bias the answer.
ANSWER:
Encode two calls as $Z = 7(a-1) + b \in \{1,\dots,49\}$; if $Z \le 40$ return $((Z-1) \bmod 10) + 1$, otherwise start again. It uses $2 \cdot 49/40 = 2.45$ calls on average.
REFRESH:
- **Rejection sampling:** if $Z$ is uniform on a finite set $S$ and $A \subset S$, then $Z$ conditioned on $Z \in A$ is uniform on $A$. Repeating independent draws until one lands in $A$ produces exactly that conditional law.
- **Geometric distribution:** if each attempt succeeds with probability $p$, independently, the number of attempts until the first success has mean $1/p$.
EXPLANATION:
No fixed number of calls can work: $k$ calls give $7^k$ equally likely outcomes, and $7^k$ is never divisible by $10$, so you can never split them into $10$ groups of equal size. You must allow the procedure to "throw away" some outcomes and try again.

Two calls give a uniform number on $\{1,\dots,49\}$ (think of the two calls as the two digits of a base-7 number). The first $40$ values split into $10$ groups of $4$, so conditionally on landing in $\{1,\dots,40\}$ each of the $10$ answers has probability $4/40 = 1/10$. The $9$ leftover values are simply rejected and we redraw. Because each attempt is independent and identical, the accepted value is exactly uniform — rejection never introduces bias, it only costs time.
SOLUTION: Rejection sampling on 49 outcomes
*Step 1.* Call `rand7()` twice to get $a, b$. The pair $(a,b)$ is uniform over $49$ equally likely pairs. Map it to $Z = 7(a-1) + b$. The map is a bijection onto $\{1,\dots,49\}$ (as in base $7$), so $Z$ is uniform on $\{1,\dots,49\}$.

*Step 2.* If $Z \le 40$, output $X = ((Z-1) \bmod 10) + 1$. Each value of $X$ is hit by exactly $4$ values of $Z$ (e.g. $X = 3$ for $Z \in \{3,13,23,33\}$).

*Step 3.* If $Z \in \{41,\dots,49\}$, discard and go back to Step 1.

*Correctness.* On a given attempt, $P(X = j,\ \text{accept}) = 4/49$ for each $j$, and $P(\text{accept}) = 40/49$. Attempts are independent, so
$$P(X = j) = \sum_{r\ge 0} \left(\tfrac{9}{49}\right)^r \cdot \tfrac{4}{49} = \frac{4/49}{1 - 9/49} = \frac{4}{40} = \frac{1}{10}.$$

*Cost.* The number of attempts is geometric with success probability $40/49$, so its mean is $49/40$, and each attempt costs $2$ calls: $2 \cdot 49/40 = 2.45$ calls on average.
SOLUTION: Recycling the rejected randomness (fewer calls)
When $Z \in \{41,\dots,49\}$, the value $Z - 40$ is itself uniform on $\{1,\dots,9\}$. Combine it with one more call: $Z' = 7(Z-41) + c \in \{1,\dots,63\}$, uniform. Accept if $Z' \le 60$ (six copies of each digit), else $Z'-60$ is uniform on $\{1,2,3\}$; combine with one more call to get a uniform on $\{1,\dots,21\}$, accept if $\le 20$, else you are left with a single outcome (no randomness left) and restart from scratch. The output is still exactly uniform at every stage, and the average number of calls drops to about $2.19$. This is optional polish; interviewers mostly want the basic rejection scheme and its correctness argument.
FOLLOWUP: A 15-sided die from two ordinary dice
You have two fair six-sided dice and need to simulate a fair $15$-sided die (outcomes $1,\dots,15$ each with probability $1/15$). How?
FOLLOWUP_ANSWER:
Use one die to choose a block of five and the other to choose within the block. Roll die $A$: map $\{1,2\}\to 0$, $\{3,4\}\to 1$, $\{5,6\}\to 2$, so $G$ is uniform on $\{0,1,2\}$. Roll die $B$: if it shows $6$, reroll it until it shows $1$–$5$; call the result $r$, uniform on $\{1,\dots,5\}$ (rejection sampling). Output $5G + r$, which is uniform on $\{1,\dots,15\}$ because $G$ and $r$ are independent and uniform: $P(5G+r = k) = \tfrac13 \cdot \tfrac15 = \tfrac1{15}$. Equivalently: roll both dice, list the $36$ ordered pairs, keep $30$ of them split into $15$ pairs of outcomes, and reroll on the other $6$.
===END===

TITLE: Waiting to beat a random threshold
QUESTION:
Let $U, X_1, X_2, \dots$ be independent, all uniform on $(0,1)$. The threshold $U$ is drawn once; then you draw $X_1, X_2, \dots$ until one exceeds it. Let
$$N = \min\{n \ge 1 : X_n > U\}.$$
Compute $\mathbb{E}[N]$ (or show it is infinite).
HINT1:
Condition on the threshold. If you knew $U = u$, what kind of random variable would $N$ be?
HINT2:
Given $U = u$, $N$ is geometric with success probability $1-u$, so $\mathbb{E}[N \mid U = u] = 1/(1-u)$. Now average over $u$ — and look carefully at what happens near $u = 1$.
ANSWER:
$\mathbb{E}[N] = +\infty$ (even though $N$ is finite with probability $1$).
REFRESH:
- **Tower property:** $\mathbb{E}[N] = \mathbb{E}\big[\mathbb{E}[N \mid U]\big]$, valid also for non-negative variables with infinite mean.
- **Tail-sum formula:** for $N \in \{1,2,\dots\}$, $\mathbb{E}[N] = \sum_{n\ge 0} P(N > n)$.
- **Probability integral transform:** if $T$ has a continuous CDF $F$, then $F(T)$ is uniform on $(0,1)$.
EXPLANATION:
For a fixed threshold $u$ you wait on average $1/(1-u)$ draws — reasonable. But the threshold is random, and with small but non-negligible probability it lands very close to $1$, where the wait explodes. Averaging $1/(1-u)$ over $u \in (0,1)$ gives $\int_0^1 \frac{du}{1-u}$, a logarithmically divergent integral: the rare huge waits dominate.

Another way to see it: $N > n$ means $U$ is the largest of the $n+1$ variables $U, X_1,\dots,X_n$, which by symmetry has probability $\frac{1}{n+1}$. So $P(N > n) = \frac{1}{n+1}$, and $\sum \frac1{n+1}$ is the harmonic series, which diverges. This second argument uses only symmetry, so it works for **any** continuous distribution, not just the uniform.
SOLUTION: Conditioning on the threshold
Given $U = u$, the $X_n$ are i.i.d. with $P(X_n > u) = 1-u$, so $N$ is geometric with parameter $1-u$ and
$$\mathbb{E}[N \mid U = u] = \frac{1}{1-u}.$$
By the tower property,
$$\mathbb{E}[N] = \int_0^1 \frac{du}{1-u} = \lim_{\varepsilon \to 0} \big[-\ln(1-u)\big]_0^{1-\varepsilon} = \lim_{\varepsilon\to 0} \ln\frac{1}{\varepsilon} = +\infty.$$
Note that $P(N < \infty) = \int_0^1 1\,du = 1$: the wait is always finite, but its mean is not.
SOLUTION: Symmetry and the harmonic series
$N > n$ iff $X_1,\dots,X_n$ are all below $U$, i.e. iff $U$ is the maximum of the $n+1$ i.i.d. continuous variables $U, X_1, \dots, X_n$. Each of them is equally likely to be the maximum (ties have probability $0$), so
$$P(N > n) = \frac{1}{n+1}.$$
Then
$$\mathbb{E}[N] = \sum_{n=0}^\infty P(N > n) = \sum_{n=0}^{\infty} \frac{1}{n+1} = 1 + \frac12 + \frac13 + \cdots = +\infty.$$
FOLLOWUP: Same question with Beta(12, 8) variables
Now $T, X_1, X_2, \dots$ are i.i.d. $\text{Beta}(12,8)$ and $N = \min\{n : X_n > T\}$. Is $\mathbb{E}[N]$ finite?
FOLLOWUP_ANSWER:
No, $\mathbb{E}[N] = +\infty$ again. The symmetry argument never used the uniform law: $P(N > n) = P(T \text{ is the largest of } T, X_1,\dots,X_n) = \frac1{n+1}$ for any continuous distribution, so $\mathbb{E}[N] = \sum_{n\ge0}\frac1{n+1} = \infty$. Equivalently, with $F$ the Beta CDF, $\mathbb{E}[N\mid T] = \frac{1}{1-F(T)}$ and $F(T)$ is uniform on $(0,1)$, which brings you back to $\int_0^1 \frac{du}{1-u} = \infty$.
===END===

TITLE: Five people born in the same month
QUESTION:
What is the smallest number of people you need in a room to be **certain** that at least five of them were born in the same calendar month, however their birthdays happen to be distributed?
HINT1:
Play the adversary: how many people can you put in the room while carefully avoiding five in any single month?
HINT2:
There are $12$ months and each can hold at most $4$ people without reaching five. What is the largest "safe" room, and what happens when one more person walks in?
ANSWER:
$49$
REFRESH:
- **Generalised pigeonhole principle:** if $n$ objects are placed in $k$ boxes and $n > k\,m$, then some box contains at least $m+1$ objects.
EXPLANATION:
"Certain" means you must beat the worst case. The worst case is the most balanced one: an adversary fills every month with exactly $4$ people, which is $12 \times 4 = 48$ people with no month reaching five. So $48$ is not enough. With $49$ people, if every month had at most $4$, there would be at most $48$ people — contradiction — so some month has at least $5$.
SOLUTION: Worst case plus pigeonhole
*48 is not enough.* Put exactly $4$ people in each of the $12$ months: $48$ people and no month contains five.

*49 is enough.* Suppose $49$ people but every month has at most $4$ of them. Summing over months, there are at most $12\cdot 4 = 48$ people, a contradiction. Hence some month contains at least $5$ people.

The minimum is $4\cdot 12 + 1 = 49$.
FOLLOWUP: Two people in the same month
What is the least number of people needed so that at least two of them are certainly born in the same month?
FOLLOWUP_ANSWER:
$13$. With $12$ people, one per month avoids any match; with $13$ people and only $12$ months, two share a month by the pigeonhole principle ($13 > 12 \cdot 1$).

SLUG: ferry-three-quarters-plus-seven

TITLE: Three quarters off, seven on
QUESTION:
A ferry leaves with some whole number of passengers. At each stop, exactly $\tfrac34$ of the passengers on board get off, and then $7$ new passengers get on. This happens at three stops in total (the first stop and two more), after which the ferry reaches its final destination. The number of passengers must be a whole number at every moment. What is the smallest possible number of passengers on board at the end?
HINT1:
Write the effect of one stop as a function $x \mapsto \dots$. What must be true of $x$ for "three quarters get off" to make sense?
HINT2:
Each stop sends $x$ to $x/4 + 7$ and requires $x$ to be divisible by $4$. Work backwards from the end: what is the smallest the load can be just before the last stop?
ANSWER:
$10$ passengers (starting from $52$: $52 \to 20 \to 12 \to 10$).
REFRESH:
- **Divisibility:** $\tfrac34 x$ is an integer iff $4 \mid x$.
- **Affine iteration:** $x_{k+1} = x_k/4 + 7$ has fixed point $x^* = 28/3$ and $x_k - x^* = (x_0 - x^*)/4^k$.
EXPLANATION:
One stop maps $x \mapsto x/4 + 7$, which only makes sense if $x$ is a multiple of $4$ (a quarter stays on). The final count is $x_3 = x_2/4 + 7$, so to make it small we want $x_2$ small — but $x_2$ itself is at least $7$ (it came from a stop that added $7$) and must be a multiple of $4$. Pushing back one level: $x_1 \ge 7$ and $4 \mid x_1$ force $x_1 \ge 8$, so $x_2 \ge 8/4 + 7 = 9$, so $x_2 \ge 12$, so $x_3 \ge 10$. Then check that $10$ is actually reachable.
SOLUTION: Backward bounds
Let $x_0$ be the initial load and $x_k$ the load after stop $k$, so $x_{k} = x_{k-1}/4 + 7$ with $4 \mid x_{k-1}$ for $k = 1,2,3$.

*Bounds.* $x_1 = x_0/4 + 7 \ge 7$ and $4 \mid x_1$, so $x_1 \ge 8$. Then $x_2 = x_1/4 + 7 \ge 9$, and $4 \mid x_2$, so $x_2 \ge 12$. Finally $x_3 = x_2/4 + 7 \ge 3 + 7 = 10$.

*Achievability.* Take $x_2 = 12$, so $x_1 = 4(12 - 7) = 20$ and $x_0 = 4(20 - 7) = 52$. Check: $52 \to 13 + 7 = 20 \to 5 + 7 = 12 \to 3 + 7 = 10$, every step divisible by $4$. (Then $x_0 = 52$ is also the smallest valid start with $x_0 > 0$, since $x_0 \equiv 52 \pmod{64}$ is forced for three stops.)

The minimum final load is $10$.
SOLUTION: Closed form of the iteration
The fixed point of $x \mapsto x/4+7$ is $x^* = 28/3$, and $x_k - \tfrac{28}{3} = (x_0 - \tfrac{28}{3})/4^k$. So $x_3 = \tfrac{28}{3} + \tfrac{3x_0 - 28}{3\cdot 64}$. The requirement $4 \mid x_0$, $4 \mid x_1$, $4 \mid x_2$ is equivalent to $x_0 \equiv 52 \pmod{64}$ (check: $4\mid x_0$; then $x_1 = x_0/4+7$ divisible by $4$ means $x_0/4 \equiv 1 \pmod 4$, i.e. $x_0 \equiv 4 \pmod{16}$; one more level gives $x_0 \equiv 52 \pmod{64}$). The smallest such $x_0 > 0$ is $52$, and $x_3$ increases with $x_0$, giving $x_3 = \tfrac{28}{3} + \tfrac{128}{192} = \tfrac{28}{3} + \tfrac{2}{3} = 10$.
FOLLOWUP: What if the routine never ends?
Same rule, but the bus repeats it at infinitely many stops and must always carry a whole number of people. What is the smallest possible initial number?
FOLLOWUP_ANSWER:
It is impossible. From the closed form $x_k = \tfrac{28}{3} + (x_0 - \tfrac{28}{3})/4^k$, the load converges to $28/3 \approx 9.33$. A sequence of integers converging to a limit is eventually equal to it, but $28/3$ is not an integer (and $x_0 = 28/3$ is not allowed either). So after finitely many stops the count stops being a whole number, whatever the start.
FOLLOWUP: Product of two dice is a square
Two fair six-sided dice are rolled and their values multiplied. What is the probability that the product is a perfect square?
FOLLOWUP_ANSWER:
$2/9$. The square products are the doubles $(1,1),(2,2),\dots,(6,6)$ (products $1,4,9,16,25,36$), plus $(1,4)$ and $(4,1)$ with product $4$. Nothing else works: a product of two different values from $\{1,\dots,6\}$ is a square only for $1\cdot 4$. That is $8$ outcomes out of $36$: $8/36 = 2/9$.

TITLE: Three ants on a triangle
QUESTION:
Three ants stand at the three corners of an equilateral triangle. At the same moment, each ant picks one of the two edges leaving its corner (clockwise or counterclockwise), with probability $\tfrac12$ each and independently of the others, and walks along it at the same speed. What is the probability that no two ants collide?
HINT1:
Each ant has only two choices, so there are only a handful of equally likely scenarios. Which ones avoid all collisions?
HINT2:
If two ants go in different rotational directions, some pair of neighbours must be walking towards each other on the same edge. So the only safe scenarios are the ones where...
ANSWER:
$\dfrac14$
REFRESH:
- **Equally likely outcomes:** with $3$ independent fair binary choices, each of the $2^3 = 8$ outcomes has probability $1/8$.
EXPLANATION:
The ants avoid each other only if they all circulate in the same rotational direction: all clockwise or all counterclockwise, like a merry-go-round. As soon as the ants do not all agree, there is one ant going clockwise whose clockwise neighbour goes counterclockwise, and those two walk head-on along the same edge. So $2$ of the $8$ equally likely configurations are safe.
SOLUTION: Counting configurations
Each ant chooses clockwise (C) or counterclockwise (A): $2^3 = 8$ equally likely configurations.

*All the same direction* (CCC or AAA): each ant walks along the edge towards the next corner, which the ant there is leaving in the same direction at the same speed — nobody meets. $2$ configurations.

*Mixed directions:* going around the triangle, the labels are not all equal, so somewhere a C is immediately followed (in the clockwise order) by an A. The C ant walks towards its clockwise neighbour along the edge joining them, and that neighbour walks back along the same edge: they collide.

Hence $P(\text{no collision}) = \dfrac{2}{8} = \dfrac14$.
SOLUTION: Follow the first ant
Whatever the first ant chooses, the other two must choose the same rotational direction as the first to avoid a collision, each with probability $\tfrac12$, independently: $\tfrac12\cdot\tfrac12 = \tfrac14$. (For $n$ ants on the corners of an $n$-gon the same argument gives $2/2^n = 2^{1-n}$.)

TITLE: Choose your coin's bias
QUESTION:
Alice and Bob each get a coin whose probability of heads they choose themselves: Alice picks $p_1$, Bob picks $p_2$. Then both coins are flipped once.
- Both heads ($HH$): Alice pays Bob $\$6$.
- Both tails ($TT$): Alice pays Bob $\$4$.
- Otherwise ($HT$ or $TH$): Bob pays Alice $\$5$.

Alice must announce $p_1$ **before** Bob chooses $p_2$. The set of values of $p_1$ for which Bob's expected gain is $\le 0$ **whatever** $p_2$ he picks is an interval $[a, b]$. Find $b - a$.
HINT1:
Write Bob's expected gain as a function of $p_1$ and $p_2$. As a function of $p_2$ alone (with $p_1$ fixed), what shape does it have?
HINT2:
Bob's expected gain is affine in $p_2$, so its maximum over $p_2 \in [0,1]$ is attained at $p_2 = 0$ or $p_2 = 1$. Require both endpoint values to be $\le 0$.
ANSWER:
$b - a = \dfrac{5}{11} - \dfrac49 = \dfrac{1}{99}$
REFRESH:
- **Affine functions on an interval:** $g(p) = \alpha + \beta p$ on $[0,1]$ attains its max and min at the endpoints, so $g \le 0$ on $[0,1]$ iff $g(0)\le 0$ and $g(1) \le 0$.
- **Independence:** $P(HH) = p_1p_2$, $P(TT) = (1-p_1)(1-p_2)$.
EXPLANATION:
Bob's payoff from any fixed $p_2$ is a weighted average of his payoffs at $p_2 = 0$ ("always tails") and $p_2 = 1$ ("always heads"), so only those two pure strategies matter. Always-heads earns Bob $6$ when Alice shows heads and loses $5$ otherwise; always-tails earns $4$ when Alice shows tails and loses $5$ otherwise. Alice must choose $p_1$ so that neither of these pure strategies is profitable: that gives two linear inequalities, $p_1 \ge 4/9$ and $p_1 \le 5/11$, a very thin window of width $1/99$.
SOLUTION: Bob's expected gain is linear in his choice
Bob's expected gain:
$$\begin{aligned}
G(p_1,p_2) &= 6p_1p_2 + 4(1-p_1)(1-p_2) - 5\big[p_1(1-p_2) + (1-p_1)p_2\big]\\
&= (4 - 9p_1) + (20p_1 - 9)\,p_2.
\end{aligned}$$
(Expand: the constant term is $4(1-p_1) - 5p_1 = 4 - 9p_1$; the coefficient of $p_2$ is $6p_1 - 4(1-p_1) + 5p_1 - 5(1-p_1) = 20p_1 - 9$.)

For fixed $p_1$ this is affine in $p_2$, so $G \le 0$ for all $p_2\in[0,1]$ iff
- $G(p_1, 0) = 4 - 9p_1 \le 0 \iff p_1 \ge \tfrac49$,
- $G(p_1, 1) = 11p_1 - 5 \le 0 \iff p_1 \le \tfrac5{11}$.

So the interval is $\left[\tfrac49, \tfrac5{11}\right]$ and
$$b - a = \frac5{11} - \frac49 = \frac{45 - 44}{99} = \frac1{99}.$$
Bonus: Alice's best choice minimises $\max(4-9p_1,\ 11p_1-5)$; the two lines cross at $20p_1 = 9$, i.e. $p_1 = 9/20$, where Bob's best expected gain is $4 - 81/20 = -\tfrac1{20}$. The game favours Alice by $5$ cents per round.

SOLUTION: Reduce to one normal

*Conclusion.*
$$\mathbb{E}|Y - X| = \sqrt5\,\sqrt{\frac2\pi} = \sqrt{\frac{10}{\pi}} \approx 1.784.$$

$$P = \frac{\binom{52-2a}{3}}{\binom{52}{4}}.$$

- **Inter-arrival times:** in a Poisson($\lambda$) process they are i.i.d. exponential with mean $1/\lambda$.
EXPLANATION:
Card-worthy clients arrive at firm 1 at rate $6 \times \tfrac16 = 1$ and at firm 2 at rate $10\times \tfrac15 = 2$, each still a Poisson process. Together they form a Poisson process of rate $3$, whose gaps are exponential with mean $1/3$.
SOLUTION: Thinning and superposition
By thinning, thank-you cards at firm 1 form a Poisson process of rate $\lambda_1 = 6\cdot\frac16 = 1$, and at firm 2 of rate $\lambda_2 = 10\cdot\frac15 = 2$; they are independent. Their superposition is Poisson with rate $\lambda_1 + \lambda_2 = 3$. The time between consecutive cards is exponential with rate $3$, so its mean is $\frac13$.
===END===

TITLE: Grab seven bills out of eight
QUESTION:
A box contains one $\$100$ bill, three $\$20$ bills and four $\$10$ bills. You draw $7$ bills at random without replacement. What is the expected total value of the bills you draw?
HINT1:
Drawing $7$ out of $8$ is the same as leaving exactly one bill behind.
HINT2:
The bill left behind is uniformly random among the $8$. Alternatively, each bill is drawn with the same probability — which one?
ANSWER:
$\$175$
REFRESH:
- **Linearity of expectation:** $\mathbb{E}\big[\sum_i v_i I_i\big] = \sum_i v_i P(I_i = 1)$.
- **Sampling without replacement:** when $k$ of $n$ items are drawn at random, each item is included with probability $k/n$.
EXPLANATION:
The box holds $100 + 60 + 40 = 200$ dollars. You take everything except one uniformly random bill, whose expected value is $200/8 = 25$. So you expect $200 - 25 = 175$.
SOLUTION: The bill left behind
Total $= 100 + 3\cdot 20 + 4\cdot 10 = 200$. The bill not drawn is uniform over the $8$ bills, with expected value $200/8 = 25$. Expected total drawn $= 200 - 25 = 175$.
SOLUTION: Indicators
Each bill is drawn with probability $7/8$, so $\mathbb{E}[\text{total}] = \frac78 \cdot 200 = 175$.

SLUG: pay-for-more-uniforms
IDS: Q-049
FIRMS: Optiver
SECTION: probability
CATEGORY: Games & optimal stopping
DIFFICULTY: hard
TITLE: Paying 2 cents per extra draw
QUESTION:
You receive one free random number, uniform on $(0,1)$. You may then generate further independent uniform numbers as many times as you like, paying $\$0.02$ for each extra one, deciding each time based on everything seen so far. When you stop, you receive the **largest** number generated (in dollars), minus what you paid. What is your expected profit under the optimal strategy?
HINT1:
Suppose your current best is $m$. Compare the expected improvement from exactly one more draw with its cost.
HINT2:
One more draw improves your best by $\mathbb{E}[(U - m)^+] = \frac{(1-m)^2}{2}$. Stop as soon as this is at most $0.02$; then compute the expected payoff and the expected number of paid draws for that threshold rule.
ANSWER:
Draw until you see a number $\ge 0.8$; expected profit $\$0.82$.
REFRESH:
- **One-step look-ahead:** in a stopping problem where, once stopping is better than one more step, it stays better forever (a "monotone" problem), the rule "stop as soon as stopping beats one more step" is optimal.
- **Geometric waiting time:** mean $1/p$ trials to the first success.
- **Uniform conditioned on an interval:** $U$ given $U > c$ is uniform on $(c,1)$, mean $\frac{1+c}{2}$.
EXPLANATION:
With current best $m$, one more draw gains $\mathbb{E}[\max(m,U)] - m = \int_m^1 (u - m)\,du = \frac{(1-m)^2}{2}$ and costs $0.02$. It is worth drawing iff $(1-m)^2 > 0.04$, i.e. $m < 0.8$. Since your best only goes up, once you are above $0.8$ you stay there, so the one-step rule is optimal: keep drawing until a number beats $0.8$. You then collect a uniform on $(0.8,1)$, worth $0.9$ on average, and you pay for the draws it took to get there: the first is free, and the number of draws is geometric with success probability $0.2$ (mean $5$), so on average $4$ paid draws, $0.08$. Net: $0.9 - 0.08 = 0.82$.
SOLUTION: Threshold rule and its value
*Threshold.* With best $m$, the gain of one extra draw is $\mathbb{E}[(U - m)^+] = \int_m^1 (u-m)\,du = \frac{(1-m)^2}{2}$. It exceeds the cost iff $\frac{(1-m)^2}{2} > 0.02 \iff m < 0.8$. The set $\{m \ge 0.8\}$ is closed under further draws (the maximum never decreases), so the problem is monotone and the one-step look-ahead rule is optimal: stop at the first number $\ge 0.8$.

*Value.* Let $N$ be the index of the first draw $\ge 0.8$; $N$ is geometric with $p = 0.2$, $\mathbb{E}[N] = 5$, and you pay for $N - 1$ draws. The stopping value is the first draw above $0.8$, uniform on $(0.8, 1)$ with mean $0.9$ (and it is the maximum, since all earlier draws were below $0.8$). So
$$\mathbb{E}[\text{profit}] = 0.9 - 0.02\,(\mathbb{E}[N] - 1) = 0.9 - 0.08 = 0.82.$$
SOLUTION: Value-function equation
Let $V(m)$ be the optimal expected future payoff with current best $m$ (future costs included). For $m \ge 0.8$, $V(m) = m$. For $m < 0.8$ guess $V(m) = c$, a constant (the old best no longer matters: you will keep going until you pass $0.8$). Then
$$c = -0.02 + \int_0^{0.8} c\,du + \int_{0.8}^1 u\,du = -0.02 + 0.8c + 0.18 \;\Rightarrow\; 0.2c = 0.16 \;\Rightarrow\; c = 0.8.$$
Note $V(m) = 0.8 \ge m$ for $m<0.8$, consistent with continuing. The first draw is free, so the game is worth
$$\mathbb{E}[V(U)] = 0.8\cdot 0.8 + \int_{0.8}^1 u\,du = 0.64 + 0.18 = 0.82.$$
===END===

CATEGORY: Continuous & geometric probability

TITLE: Variance of the longer piece
QUESTION:
A rope of length $1$ metre is cut at a point $X$ chosen uniformly on $(0,1)$. Let $L = \max(X, 1-X)$ be the length of the longer piece. Compute $\operatorname{Var}(L)$.
HINT1:
What values can $L$ take, and is any of them more likely than another?
HINT2:
$L$ is uniform on $(\tfrac12, 1)$: check $P(L \le \ell)$ for $\ell\in(\tfrac12,1)$. Then use the variance of a uniform distribution.
ANSWER:
$\dfrac1{48}$ (square metres)
REFRESH:
- **Uniform distribution:** if $V\sim U(a,b)$ then $\mathbb{E}[V] = \frac{a+b}{2}$ and $\operatorname{Var}(V) = \frac{(b-a)^2}{12}$.
- **Variance formula:** $\operatorname{Var}(L) = \mathbb{E}[L^2] - (\mathbb{E}L)^2$.
EXPLANATION:
Folding the interval $(0,1)$ at its midpoint maps $X$ to $L$: the cut at $x$ and the cut at $1-x$ give the same longer piece. Folding a uniform distribution in half gives a uniform distribution on the half: $L \sim U(\tfrac12, 1)$, an interval of length $\tfrac12$, so $\operatorname{Var}(L) = \frac{(1/2)^2}{12} = \frac1{48}$.
SOLUTION: Distribution of L
For $\ell \in [\tfrac12, 1]$: $L \le \ell \iff 1-\ell \le X \le \ell$, so $P(L\le\ell) = 2\ell - 1$, the CDF of $U(\tfrac12,1)$. Hence
$$\operatorname{Var}(L) = \frac{(1 - \tfrac12)^2}{12} = \frac1{48}.$$
SOLUTION: Direct moments
$\mathbb{E}[L] = 2\int_{1/2}^1 x\,dx = \frac34$ and $\mathbb{E}[L^2] = 2\int_{1/2}^1 x^2\,dx = \frac23\left(1 - \frac18\right) = \frac7{12}$. So
$$\operatorname{Var}(L) = \frac7{12} - \frac9{16} = \frac{28 - 27}{48} = \frac1{48}.$$
===END===
